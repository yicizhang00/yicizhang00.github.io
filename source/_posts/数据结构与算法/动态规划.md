# 动态规划

## 最优子结构
原问题的最优解 = 由若干子问题的最优解组合而成

如果子问题的最优解是稳定的、不依赖外部约束的，那就满足最优子结构。

> [!WARNING]
> 具有最优子结构的问题也可以采用贪心和分治算法解决
> 其主要区别在与这个子问题是否是重叠的，即下一步的求解依赖于上一步的状态。
## 无后效性
已经求解的子问题，不会受到后续决策影响。
> [!WARNING]
> 如果后续决策会影响已经求解的部分，那么需要更新之前求解的部分，这会导致问题复杂度急剧上升。

## 重叠子问题

如果有大量的重叠子问题，我们可以用空间将这些子问题的解存储下来，避免重复求解相同的子问题，从而提升效率．

## 求解思路
1. 判断是否满足三个条件
2. 定义`dp[][] `的含义
3. 找状态转移方程，定义$dp[i] = ...$
4. 确定初始状态以及边界条件
5. 优化空间/时间：
- 滚动数组
- 前缀和/差分
- 单调队列
- 状态压缩

# 最长公共子序列

> 给定两个字符串 text1 和 text2，返回它们的最长公共子序列的长度。如果不存在公共子序列，返回 0。

定义`dp[i][j]`为text1的第i位和text2的第j位最长公共子序列的长度。
$$
dp[i][j] = \begin{cases}  dp[i-1][j-1] + 1, & \text{if } text1[i-1] == text2[j-1] \\  \max(dp[i-1][j],\, dp[i][j-1]), & \text{if } text1[i-1] \ne text2[j-1]  \end{cases}$$

定义边界：
`dp[0][j]`和`dp[i][0]`恒为0，为哨兵行/列，代表空串与任何字符串公共子序列长度为0。

时间复杂度：O(mn)

## 空间优化
在二维DP中`dp[i][j]`的计算仅仅依赖于`dp[i-1][j-1]`,`dp[i-1][j]`,`dp[i][j-1]`，意味着第`i`行的计算只依赖于当前行或`i-1`行。

既然只依赖于当前或上一行，我们其实只需要一个`2 × (n+1)`的数组就足够了，`dp[0][]`存上一行，`dp[1][]`存当前行。计算过程如下：
1. 算第一行时：把 `dp[0]` 当成上一行，结果全写进 `dp[1]`。

2. 算第二行时：把 `dp[1]` 当成上一行，结果全写进 `dp[0]`（把最早无用的旧数据直接覆盖）。

3. 算第三行时：再把 `dp[0]` 当成上一行，结果写进 `dp[1]`。

这就是**滚动数组**最基础的原型。代码用 `i % 2` 切换行号，逻辑与普通二维一模一样：
```java
int[][] dp = new int[2][n + 1];

for (int i = 1; i <= m; i++) {
    int curr = i % 2;       // 当前行：只能是 0 或 1
    int prev = (i - 1) % 2; // 上一行：只能是 1 或 0
    
    for (int j = 1; j <= n; j++) {
        if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
            dp[curr][j] = dp[prev][j - 1] + 1;
        } else {
            dp[curr][j] = Math.max(dp[prev][j], dp[curr][j - 1]);
        }
    }
}
return dp[m % 2][n];
```
到这里空间已经从`O(mn)`降为`O(2n)`，但是我们依然可以再进一步去掉行号的索引。

![](https://raw.githubusercontent.com/yicizhang00/image_host/main/blog-img/20261009173155097.png)

由于内循环是按列递增的，我们在计算`(i,j)`部分的时候并不关心橙色部分的值，意味着我们可以直接删除橙色部分的数组内容而不影响其计算，若如此做，这个二维数组可以进一步压缩为一维数组。

```
位置:      0    1    2   ...  j-1     j     j+1  ...   n
状态:    [新] [新] [新] ...  [新]   [旧]   [旧]  ...  [旧]
                              ↑      ↑
                            当前刚算  还没算，
                            出来的   存的还是
                            当前行   上一行
```
当我们压缩为一维数组之后有一个分界线在`j`的左边，即`j`左边数为已经更新后的值，而`j`右边的数为上一行的旧值，但是有一个问题是`dp[i-1][j-1]`的值多出来，他对应的下一行已经被更新为新值，我们需要一个临时变量额外存储这一个值。

```java
int[] dp = new int[n + 1];

for (int i = 1; i <= m; i++) {
    int topLeft = 0; // 临时变量：初始是 dp[i-1][0]，等于 0

    for (int j = 1; j <= n; j++) {
        int temp = dp[j]; // 1. 在 dp[j] 被覆盖前，先备份（它就是下一轮的 topLeft）

        if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
            dp[j] = topLeft + 1; // 2. 用上一轮存下来的左上角
        } else {
            dp[j] = Math.max(dp[j], dp[j - 1]); // 正上方(旧dp[j]) vs 正左方(新dp[j-1])
        }

        topLeft = temp; // 3. 把备份给手提箱，供 j+1 使用
    }
}
```
